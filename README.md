# Week 4 - Employee Data Analysis Project

## Overview

This project is a Python-based Employee Data Analysis project developed as part of Week 4. It demonstrates data handling and analysis using Pandas and CSV files.

## Objectives

The project performs the following tasks:

- Loads employee data from a CSV file.
- Calculates the average employee salary.
- Counts employees in each department.
- Filters employees based on a salary threshold.
- Exports the filtered employee data to a new CSV file.

## Technologies Used

- Python
- Pandas
- CSV

## Files

```text

```

## How to Run

First install Pandas:

```bash
pip install pandas
```

Then run:

```bash
python employee_analysis.py
```

## Features

### Average Salary

The program calculates the average salary of all employees.

### Department Count

The program counts how many employees belong to each department.

### Salary Filtering

Employees earning more than ₹50,000 are displayed.

### CSV Export

The filtered employee records are exported to:

```text
high_salary_employees.csv
```
